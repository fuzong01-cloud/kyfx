# 知禾 · 2027考研复习

面向北京农学院341《农业知识综合三（智慧农业技术）》和821《现代农业与农业信息化》的完整复习系统，沿用旧版的模块学习、考纲地图、题库练习、题目解析、举一反三、主动回忆、进度记录和备份流程。

## 复习依据

- 两份最新考试大纲决定复习范围；大纲原文按考点编号展示。
- 学生总结作为主要复习材料：`农学概论 简化版.docx`、`农业信息化终极背诵版.pdf`、`人工智能.docx`。
- 《农学概论（第二版）》和《农业信息化导论》作为辅助教材，只用于理解和核对部分概念。书籍原文件不上传。
- 题库中的每一道题都是按考纲新编的练习，原资料里没有这些题干。题目逐一标明“新编练习”，并显示对应考纲和复习资料。整理解析不是官方答案。

资料书架当前只展示三份学生总结中与考纲对应的章节。341只保留人工智能和农学概论的复习内容。

## 如何复习

1. 在“模块学习”按341人工智能、农学概论和821农业信息化分模块学习。
2. 在“考纲地图”查看每条考纲的原文、对应主题和练习题。
3. 先独立作答，再查看参考要点、易错点和资料依据；通过变式练习举一反三。
4. 在“主动回忆”按间隔复习队列练习，并用“还不会 / 有点模糊 / 基本会答 / 能举一反三”记录掌握程度。
5. 在“学习记录”查看进度、保存个人笔记，并导出或导入JSON备份。

## 数据和隐私

网站无需登录、WPS或在线数据库。学习进度、草稿、笔记、收藏和每日目标保存在当前浏览器的localStorage，不会上传。更换设备、浏览器或网站域名时，使用“学习记录”里的导出和导入功能迁移；清除站点数据前请先备份。

## 本地运行

需要Node.js 20或更新版本，无第三方运行依赖。

```sh
npm run build
npm run dev
```

打开 `http://127.0.0.1:4173`。构建生成的成品位于`dist/`，包括题库、资料书架、模块复习提纲和题目—考纲对照索引。

## Cloudflare Pages

GitHub仓库：`fuzong01-cloud/kyfx`。在Cloudflare Pages导入此仓库并配置：

| 设置 | 值 |
| --- | --- |
| 生产分支 | `main` |
| 框架预设 | `None` |
| 构建命令 | `npm run build` |
| 构建输出目录 | `dist` |
| 根目录 | 留空 |
| Node版本 | 22（环境变量`NODE_VERSION=22`） |

Cloudflare项目需要由账号持有人创建并绑定仓库；提交代码本身不会自动创建Pages项目。绑定后，推送`main`分支会触发部署。
