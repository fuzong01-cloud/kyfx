# 知禾 · 341 与 821 考研复习

知禾围绕用户提供的两份341、821考试大纲组织复习，以指定的上届学生总结为主要复习内容，并用两本教材辅助核对已确认概念。

## 纳入本项目的资料

- 《农业知识综合三（智慧农业技术）》（341）考试大纲
- 《现代农业与农业信息化》（821）考试大纲
- 农学概论简化版
- 农业信息化终极背诵版
- 人工智能总结
- 李存东《农学概论》（第二版）与王玉洁《农业信息化导论》的选定概念核对说明

考点以考纲为准。学生总结是复习主体，不作为官方答案；教材只在已核实的概念处提供补充。教材 PDF 本身不打包发布。

## 系统功能

- 按341和821考纲分模块浏览考点。
- 在对应考点内阅读相关学生总结和已核实的教材辅助说明。
- 标记考点复习状态，记录个人理解，并用考纲要点进行主动回忆。
- 导出、导入个人进度 JSON 备份。

仅纳入上列资料作为复习内容。

## 本地预览

需要 Node.js 20 或更新版本，无第三方依赖：

```sh
npm run dev
```

打开 `http://127.0.0.1:4173`。

## Cloudflare Pages

连接 GitHub 仓库 `fuzong01-cloud/kyfx`，构建命令为 `npm run build`，输出目录为 `dist`，框架预设选 `None`。这是纯静态网站，可直接由 Pages 构建托管。

## 数据保存

学习状态、个人笔记和自测记录保存在当前浏览器。换设备或清除浏览器数据前，请从“学习进度”导出备份。当前没有账号登录或云端同步。
