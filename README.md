# 知序 · 个人复习系统模板

通用个人复习系统空白版。项目提供课程、知识点、题库、主动回忆、进度统计和 JSON 备份。页面不预置任何特定考试、教材、历年真题或附件里的资料内容。

## 本地预览

需要 Node.js 20 或更新版本，不需要安装第三方依赖：

```sh
npm run dev
```

然后打开 `http://127.0.0.1:4173`。

## 发布到 Cloudflare Pages

导入 GitHub 仓库 `fuzong01-cloud/kyfx`，构建命令设为 `npm run build`，输出目录设为 `dist`，框架选择 `None`。项目是纯静态页面，不需要 WPS、数据库、环境变量或 cloudflared 隧道。

## 数据保存

课程、知识点、题目、笔记和复习进度保存在当前浏览器的 `localStorage`。此版本没有账号注册、云端同步或跨设备共享；换设备或清除浏览器数据前请导出 JSON 备份，再在另一设备导入。

若未来需要真正的账号登录和跨设备同步，需要增加具备身份验证和数据库能力的后端服务；不要把密码直接存进浏览器或公开表格。

## 复习流程

1. 新建课程并添加知识点。
2. 在知识点下创建问答练习，填入问题与参考答案。
3. 使用“主动回忆”先尝试作答，再按真实掌握情况自评。
4. 在学习记录页调整每日目标并导入、导出个人数据。
